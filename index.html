Problem Understanding

Problem Statement & Machine Learning Objective

Educational & Economic Challenge

Higher education institutions worldwide face high student attrition rates—frequently ranging between 15% and 35% in undergraduate programs. Student dropouts result in significant financial tuition losses for universities and diminished career opportunities for students.

  • For Students: Incomplete degree credentials, lost financial tuition investment, and lower earning potential.
  • For Universities: Loss of tuition revenue, diminished rankings, and inefficient counseling allocation.
Supervised Learning Classification Problem Logistic Regression

ML Target Variable Definition

Target variable $Y$ represents student outcome status:

  • Binary Target Encoding 1 = Dropout, 0 = Retained
  • Primary Optimization Metric Recall (Sensitivity) & ROC-AUC
  • Prediction Window End of 1st / 2nd Academic Semester

Supervised binary classification predicting student dropout risk probability $P(\text{Dropout} \mid X)$ based on early academic performance, tuition payment status, debtor status, and enrollment age.
